# Jest Testing Practice

Repositório dedicado à prática e consolidação de **testes automatizados com Jest e TypeScript**, com exercícios progressivos voltados para situações comuns no desenvolvimento backend.

A proposta é transformar cada exercício em uma oportunidade de praticar a escrita de testes, entender cenários de sucesso e erro e desenvolver uma mentalidade orientada à qualidade e confiabilidade do código.

## 🎯 Objetivos

- Consolidar os fundamentos do Jest
- Praticar testes unitários com TypeScript
- Aprender a identificar cenários relevantes para cada função
- Trabalhar com regras de negócio e casos de erro
- Aplicar testes em serviços e componentes comuns de aplicações backend
- Construir uma rotina de desenvolvimento orientada por testes
